# Play-test round 5 (multi-bot)
Several play-tester sessions (different personas) each write one report here: `pt5-<persona>.md`, screenshots in
`docs/screenshots/pt5-<persona>-*.png`. Format for every report:
1. Setup (start year, region, difficulty, what you built) — 5 lines max.
2. Timeline: net worth / cash / trains every 5 game years (table).
3. Findings, most important first. Each: **[bug|balance|UX|idea]** title — repro steps — evidence (numbers or
   screenshot) — severity (high/med/low).
4. Fun & pacing: 3–5 sentences, honest.
5. Top 3 things to fix.
Rules: do NOT change game code or tests. Only commit your own report + your screenshots. Look at your screenshots.
